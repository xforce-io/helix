# 名词表

| 规范名 | 一句话定义 | 禁止别称 |
|---|---|---|
| 规范执行状态 | 由 Helix 宿主维护、可版本化验证且足以决定下一步任务执行的领域状态投影。 | 上下文、聊天记录、记忆 |
| 事件证据 | 由 milkie 记录的不可变事件、对象引用及其完整性信息，用于审计和回放。 | 日志、历史文本 |
| 状态信封 | 在 Helix 与模型之间传递的有版本、有限大小且可校验的规范执行状态表示。 | ContextEnvelope、提示词状态 |
| Harness | 将模型调用、领域工具、规范执行状态和验证器编排为一次可执行任务的 Helix 宿主程序。 | agent、工作流 |
